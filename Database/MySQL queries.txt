Q21. Employee Table Design

Create an employees table with these requirements:

id → integer, automatically generated and Primary Key
name → cannot be NULL
email → must be unique
age → cannot be less than 18
salary → cannot be less than 0
city → default should be Pune

Write the complete CREATE TABLE query.

ANS: CREATE TABLE employees(id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(70) NOT NULL, email VARCHAR(90) UNIQUE, age INT, salary BIGINT, city VARCHAR(50) DEFAULT 'Pune', CHECK(age >= 18), CHECK(salary >= 0));
-----------------------------------------------------------------------------------------------------------------------------------------------------------
